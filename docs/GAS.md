# Gas analysis

**Setup.** Measured on 2026-09-24 on a local nitro devnode:
- nitro-node v3.11.4, ArbOS 61, L1 price set to 0;
- traced with `debug_traceTransaction` (call tracer).

**What was measured.** A real `pay` transaction submitted through the relayer:
- **Proof:** an UltraHonk proof of a WebAuthn P-256 assertion, made in the browser (bb.js 5.2.0, headless Chrome, 8 threads).
- **Verifier:** generated by `bb write_solidity_verifier -t evm --optimized` with bb 5.2.0 (a ZK verifier).

## Where one `pay` spends its gas

| Frame | Gas | Notes |
|---|---:|---|
| Transaction total | 1,073,882 | 9,220 bytes of calldata |
| ├─ intrinsic + calldata + EIP-1167 proxy | ~166,350 | 21,000 + 16 gas per non-zero byte |
| └─ `VeraKeyAccount.pay` (Stylus, via DELEGATECALL) | 907,528 | |
| &nbsp;&nbsp;&nbsp;├─ SHA-256 of `clientDataJSON` (precompile `0x02`) | 120 | |
| &nbsp;&nbsp;&nbsp;├─ `HonkVerifier.verify` (Solidity, bb-generated, optimized) | 712,554 | see below |
| &nbsp;&nbsp;&nbsp;└─ account logic: JSON/base64url checks, nonce, policy, 2 × USDG `transfer`, events | ~194,850 | |

## Before and after the verifier upgrade

| | Before | After |
|---|---|---|
| Toolchain | nargo 1.0.0-beta.22, bb 5.0.0-nightly.20260522 | nargo 1.0.0-beta.25, bb 5.2.0 |
| Solidity verifier | default generator (`-t evm`), with libraries | `-t evm --optimized`: one contract, 16,742 bytes deployed |
| Circuit | 81,605 gates (2^17) | 56,528 gates (2^16) |
| Proof | 9,152 bytes | 8,768 bytes |
| Proving in headless Chrome, 8 threads | ~2.1 s | 1.85 s (median of 3) |
| `modexp` calls in `verify` | 466 (1,882,820 gas) | 3 (12,144 gas) |
| `HonkVerifier.verify` | 3,781,398 | 712,554 |
| `pay` | 4,171,302 | 1,073,882 |
| `pay` on Arbitrum One | ≈ $0.22 | ≈ $0.06 |

The dollar figures use prices read on 2026-09-24:
- a 0.02 gwei gas price (`ArbGasInfo.getPricesInWei`);
- an ETH price of $2,668.

On Arbitrum One, the proof's calldata adds about $0.002 of L1 data fee (about 73 gwei per byte).

**Where the savings came from:**
- **Smaller circuit.** bb 5.x checks secp256r1 signatures with fewer gates (81,605 down to 56,528). The circuit now fits in 2^16, so:
  - there is one less sumcheck round;
  - the proof is 384 bytes smaller;
  - proving is faster.
- **Batched inversions.** The `--optimized` generator batches field inversions, so `verify` makes 3 `modexp` calls instead of 466.
  - Most of the saving comes from this.
  - With bb 5.2.0 but the default generator, `verify` still costs 3,693,229 gas (455 `modexp` calls).

## What is left

- **Elliptic-curve precompiles** (`ecMul`, `ecAdd`, `ecPairing`): about 463,550 gas, 65% of `verify`.
  - They have fixed prices, so moving the verifier to Stylus cannot make them cheaper.
- **Field arithmetic and the keccak transcript:** about 237k gas.
  - This is the part a Stylus verifier could still reduce.
- **Account creation:** about 479,000 gas.
  - That covers a CREATE2 clone plus the first writes to its configuration and owner slots.
  - A clone with immutable arguments would remove most of those writes.
  - The earlier figure of 80,812 gas measured a call for an account that already existed, which returns early.
- **Baseline for comparison:** a non-private passkey signature check through `P256VERIFY` costs 3,450 gas. The ZK proof costs about 200 times that.
